# modoo
대구모두심리상담센터


## 집단상담 페이지

- 공개 주소: https://daegumodoo.com/group/
- `group/`의 HTML, CSS, JavaScript 및 이미지만으로 GitHub Pages에서 작동합니다.
- 신청 영역 `#google-form-container`는 Google Forms를 삽입합니다. 응답은 연결된 비공개 Google 스프레드시트로 수집됩니다. 응답 데이터나 인증정보를 이 공개 저장소에 추가하지 마세요.
- 향후 Apps Script 전환 시 위 신청 영역만 교체하고 기존 응답 시트를 연결할 수 있습니다. 현재는 Apps Script를 사용하지 않습니다.
- 원본 ChatGPT Site의 서버, 로그인, 관리자 페이지 및 데이터베이스는 이 저장소에 포함하지 않습니다.
